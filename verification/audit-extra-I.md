Scope: `langevin_fisher_decay`, `langevin_fisher_dini`, `IsSDESolution`, `normalization_sde`, `temperature_sde`, `temperature_cutoff`, `mixing_time_w2_rigid`, `mixing_time_kl_rigid`, defs `mixingTimeW2`, `mixingTimeKL`.

## Shared definitions touched
- `IsBrownianReal` (Mathlib): finite-dimensional laws of BM plus a.s. continuous paths. So `IsStdBrownian` = independent real BMs, and the scaled process in `normalization_sde` is a genuine statement (proved: `isStdBrownian_scale`).
- `gibbs V` = unnormalized `e^{-V}dx`; "probability" is a hypothesis (`hp` / `IsLangevin`). No filtration/adaptedness is modeled for solutions (same as the already audited `IsLangevinSolution`); harmless here, because under `Hess V >= rho > 0` the pathwise equation `X - sB = x0 - a int grad V(X)` is an ODE with one-sided Lipschitz drift, so the solution is a measurable functional of the path of `B` (strong solution automatically).

## 1. IsSDESolution and normalization_sde: faithful
- `IsSDESolution V a s B P x0 X` := a.s. (`Continuous X.w` and for all t, `X_t = x0 - a * int_0^t grad V(X_r) dr + s * B_t`). Signs and constants are those of `dX = -a grad V dt + s dB`. `IsLangevinSolution` is exactly the case `(a,s) = (1, sqrt 2)` (proved as `isLangevinSolution_iff_sde`, `simp`). The integrand `grad V (X r.toNNReal w)` is continuous a.s. when `V` is C^1, so no integral-of-nonintegrable junk in the used cases (all uses carry `ContDiff 2`).
- Constants for `normalization_sde`: with `X_t = x0 - int_0^t grad V(X) + sqrt2 B_t`, `X_{ct} = x0 - c int_0^t grad V(X_{cu}) du + sqrt2 sqrt c * (B_{ct}/sqrt c)`. So drift coefficient `c`, noise `sqrt2 sqrt c = sqrt(2c)`, and `B'_t = (sqrt c)^{-1} B_{ct}` which is standard BM. This matches the manuscript's `dX^{(alpha)} = -alpha grad V dt + sqrt(2 alpha) dB` (lines 825-828, where `B` is understood to be a new BM, as stated explicitly in Lean). Initial condition `x0` preserved. Time `c.toNNReal * t`, with `c > 0` so `toNNReal c = c`; no truncation. First conjunct (rescaled BM is standard BM) is a correct and useful addition.
- Not vacuous: `IsLangevin` is satisfiable (OU: explicit pathwise solution; existence of BM classical), as flagged. "Generator `alpha L`" and "cutoff at `t*/alpha`" parts of the manuscript paragraph are in `normalization_cutoff` (previous audit), not here.
- Remark (minor, no action needed): the statement only claims the integral equation for the same `P`; the filtration of `B'` is not modeled (nothing in the project models filtrations).

## 2. langevin_fisher_decay: faithful (slightly stronger than printed)
- Statement: for every initial law `nu` (probability), all `s <= t` (including `s = 0`), `I(mu_t) <= ofReal(exp(-2 rho (t-s))) * I(mu_s)` in `R>=0∞`. Manuscript (eq:expdecI, line 1159): for `t >= t1 > 0`, `I(mu_t|mu) <= e^{-2rho(t-t1)} I(mu_{t1}|mu)`, started from a Dirac. Lean allows `s = 0` and arbitrary `nu`. This is true (Bakry-Emery, valid with `I = +inf`) and is kernel-proved. ENNReal conventions: `ofReal(exp(..)) > 0` and finite, so `ofReal * ⊤ = ⊤` and no `0 * ⊤` junk arises; the inequality is the right one when `I(mu_s) = ⊤` (trivial) and when it is finite (then forces `I(mu_t)` finite). `ofReal` truncation not an issue since `exp > 0`. `(t:R) - s >= 0` by `s <= t`.
- Same bind convention as `langevin_entropy_decay`: `nu.bind (fun x => P.map (X x t))` (law of `X_t` started from `nu`). `Measure.bind` = `join (map _)` would give `0` for a non-measurable kernel, but then the statement would not be provable (the project proves the kernel is Markov); not junk-exploitable here since `I(0 measure)` would be the junk; the proof goes via `law_bind_eq_comp`, so it is the genuine law.
- Hypotheses: `IsLangevin`, `0 < rho`, Hess bound (needed). No `0 < d` (unlike `langevin_entropy_decay`): for `d = 0` everything is trivially `0 <= 0`, and it is kernel-checked, so fine. Not flagged but harmless.
- Fisher information definition (shared, previously audited): `fisherInfo` uses the weak gradient identity against Lebesgue (`int ... dx` without measure) with `G in L^2(gibbs)`; since `gibbs ~ volume` (positive density) this is the usual `4 int |grad sqrt h|^2 dmu`. Not re-audited.

## 3. langevin_fisher_dini: faithful with remarks (true, nonvacuous, but formally redundant)
- Statement: at every `t` with `I(mu_t) != ⊤`, for all `eps > 0`, eventually as `h -> 0+` (`nhdsWithin 0 (Ioi 0)`, so `h > 0` eventually and `h.toNNReal = h`), `(I(t+h).toReal - I(t).toReal)/h <= -2 rho I(t).toReal + eps`. This is exactly `D^+ I(t) <= -2 rho I(t)` (upper right Dini derivative), the right weak form of `partial_t I <= -2 rho I` (manuscript line 1152; the manuscript derives `expdecI` from it by Gronwall).
- `toReal` is meaningful: `I(t) != ⊤` is assumed, and `I(t+h) <= e^{-2 rho h} I(t) < ⊤` by the decay statement, so there is no `toReal ⊤ = 0` junk affecting the inequality. Without `ht` the statement would be junk-prone; with `ht` it is correct. `h.toNNReal` shift is harmless for `h > 0`.
- Non-vacuous: any `nu` with `I(mu_t) < ⊤` (e.g. OU from a Dirac, `t > 0`, `I = rho d e^{-4 rho t}/(1-e^{-2 rho t}) + rho^2 e^{-2 rho t}|x0|^2 < ⊤`; or `nu = mu`, `I = 0`) satisfies the hypothesis; at `t = 0` from a Dirac the hypothesis fails (`I = ⊤`) so the statement says nothing there, which is correct.
- Remark (not a defect): it is a consequence of `langevin_fisher_decay` (direction reversed compared with the manuscript's Gronwall derivation: Lean derives Dini from decay, the paper derives decay from the differential inequality). Hence it adds no mathematical content beyond `langevin_fisher_decay`; it is faithful to the differential-inequality sentence but weaker than a genuine derivative statement (`I` differentiable with `I' <= -2 rho I`), as the docstring admits ("no derivative is claimed"). Severity: none (documented).

## 4. temperature_sde: faithful with remarks
- Scaling: `Y` solves `dY = -grad V dt + sqrt2 sigma dB`; `c = sigma^{-2}`; `Z_u = Y_{cu}` solves `dZ = -c grad V du + sqrt2 sigma sqrt c dB'`, and `sigma sqrt c = 1`, `c grad V = grad(V/sigma^2)`, so `Z` is Langevin (1, sqrt2) for `V/sigma^2` with `B'_u = sigma B_{u/sigma^2}` (docstring says exactly this). This matches manuscript lines 855-857 (`alpha = sigma^2` and `V/sigma^2`; their `X^{(alpha)}_t = X_{alpha t}` with `X` for `V/sigma^2` gives `Y_t = X_{sigma^2 t}`, i.e. `X_u = Y_{u/sigma^2}`: same direction as Lean). Noise coefficient in the hypothesis, `sqrt 2 * sigma = sqrt(2 sigma^2)`, matches line 845.
- Invariance conclusion: manuscript's invariant law `mu_sigma = Z_sigma^{-1} e^{-V/sigma^2}dx`; Lean uses `gibbs(V/sigma^2)` unnormalized, assumed probability (`hp`). Invariance of `e^{-V/sigma^2}` for generator `sigma^2 Delta - grad V . grad` is correct (stationary Fokker-Planck: `sigma^2 grad p = -p grad V`). The statement `(gibbs W).bind (fun x => P.map (Y x t)) = gibbs W` is not junk-satisfiable: both sides are probability measures (`bind` of a non-measurable kernel would be `0 != gibbs W`).
- Amendments (all flagged except the first remark):
  (a) `hp` "probability" vs. docstring in Challenge "normalizable": the hypothesis is `Z_sigma = 1`, not just `Z_sigma < ∞`. Since `ContDiff 2` plus `Hess V >= rho > 0` already implies integrability, the real extra content is the normalization `Z_sigma = 1`. This costs no generality for the SDE (only `grad V` enters; one may add a constant to `V`), and it is how `IsLangevin` is defined project-wide. For one fixed `V` it cannot hold for all `sigma` simultaneously, but the statement is per `sigma`. Suggest wording "normalized (`Z_sigma = 1`, w.l.o.g. by adding a constant to `V`)" in the docstring. Severity: docstring only.
  (b) `C^2` and `Hess V >= rho > 0`: added, flagged ("convexity, not in the manuscript"). Part (i) (Langevin reduction) does not use the Hess bound, only `C^2` and `hp`; part (ii) (invariance) is proved using it. The statement is therefore weaker than the manuscript's general `V` in (ii), but the hypothesis is the standing CD(rho, inf) assumption of the whole paper. Harmless; necessary for the project's proof technique, not for truth.
  (c) `B` and `Y` given by hypothesis (`hY` for every `x0`, `IsStdBrownian`); no existence claimed. Fine.
- Satisfiable: `V = |x|^2/2 + const`, `rho = 1`, constant chosen with `(2 pi sigma^2)^{d/2} e^{-const/sigma^2} = 1`; `Y` the OU solution driven by a BM.

## 5. temperature_cutoff: faithful with remarks (one interpretation to flag)
- Rigid case reading. Manuscript: "in the rigid case `rho = lambda_1`, the cutoff critical time is free of sigma" (line 859), with `lambda_1` the spectral gap of the generator `L_sigma = sigma^2 Delta - grad V . grad`. `spec gap(L_sigma) = sigma^2 spectralGap(V/sigma^2)` (since `L_sigma = sigma^2 * L_{V/sigma^2}`), so `hgap : rho n = sigma^2 * spectralGap(V n/sigma^2)` together with `hHess : Hess V_n >= rho_n` is precisely "`rho = lambda_1` (of `L_sigma`) and `CD(rho, inf)`", i.e. `IsRigidSequence` for `V_n/sigma^2` with parameter `rho_n/sigma^2`. Hand check, OU: `V = |x|^2/2 + c`, `Hess V = 1`; `V/sigma^2 = (1/sigma^2)|x|^2/2 + c/sigma^2` is OU with parameter `1/sigma^2`, so `spectralGap(V/sigma^2) = 1/sigma^2` (`ou_first_eigenspace`) and `sigma^2 * (1/sigma^2) = 1 = rho n`, and `Hess V = 1 >= 1`. So the hypotheses are consistent and non-vacuous (also for `V = rho|x|^2/2 + W` with `W` convex, diagonal-invariant: linear eigenfunction, gap `rho/sigma^2`, any `sigma`).
- Always `spectralGap(V/sigma^2) >= rho/sigma^2` (Bakry-Emery on `V/sigma^2`), so `hgap` is the equality case and not over-strong: it is exactly rigidity at temperature `sigma`. The alternative reading "`V` rigid at `sigma = 1`" would be a different hypothesis; the Lean one is the natural one (rigidity for the diffusion actually run), and it is the hypothesis under which the proof reduces to `wasserstein_cutoff` / `information_cutoff` for `V_n/sigma^2`. Interpretation point worth a docstring sentence, already flagged ("rigid is the hypothesis `rho_n = sigma^2 lambda_1(V_n/sigma^2)`"). Not a defect.
- Critical time `criticalTime n (rho n) = log n/(2 rho_n)` is free of `sigma` (given `rho_n`). By `normalization_cutoff` with `alpha = sigma^{-2}`: `Y` cuts off at `t_Y` iff `Z_u = Y_{alpha u}` cuts off at `t_Y/alpha = sigma^2 t_Y`; and for `Z`, `criticalTime n (rho_n/sigma^2) = sigma^2 log n/(2 rho_n)`. Consistent (`t_Y = log n/(2 rho_n)`). Direction of the time change correct.
- `liminf ofReal(rho n) > 0` equals `liminf ofReal(sigma^{-2} rho n) > 0` for fixed `sigma > 0`; `rho = o(log)` equals `gap(V/sigma^2) = o(log)`. Conclusions: W2, Fisher, KL, TV relative to `gibbs(V n/sigma^2)` (the invariant law mu_sigma), start set `meanBall (V n/sigma^2) c` = ball of radius `c sqrt n` around the mean of mu_sigma; `c > 0` arbitrary, so fine. Cutoff values (`⊤ , 0` and TV `1, 0`) as in Cor. 1.3/1.4. The manuscript sentence is only a one-line remark; the Lean statement is the faithful precise form. Cubes not claimed (not required).
- Hypotheses `hY, hp, hρ, hHess, hgap` only for `0 < n`: correct (irrelevant at `n = 0`, eventually in `atTop`). No `0 < d` problems: the invoked theorems are for `n > 0`.
- Junk check: `rho n` for `n = 0` unconstrained but `criticalTime 0 _ = 0` and `atTop` ignores it; `=o[atTop]` fine.

## 6. mixingTimeW2 / mixingTimeKL and the two mixing theorems: faithful
- Definitions: `⨅ (t : R>=0) (_ : worst P X S delta t <= ofReal eta), (t : R>=0∞)` with `delta = W2(., mu)` (not squared) or `klDiv . mu`. This is the inf over `t >= 0` of the worst-case discrepancy `<= eta`, as in the docstring. `⨅ ∅ = ⊤` (docstring says `+inf if empty`). For `eta > 0` (all uses), `ofReal eta = eta`; no truncation. W2 vs. W2^2 threshold: the theorems hold for every `eta > 0`, so squared/unsquared are equivalent families of statements. `klDiv nu mu` in `R>=0∞` is `⊤` when `nu` not `<< mu` (e.g. Dirac at `t = 0`), the true relative entropy for probability measures. `worst` takes `sup` over `S` of `delta(Law(X_t^{x0}))`, `t.toNNReal` with `t : R>=0` coerced: exact.
- `mixing_time_w2_rigid` conjuncts: (a) `t0 n < ⊤` eventually (so `toReal` below is not junk), (b) `t0.toReal / criticalTime -> 1` i.e. `(log n/(2 lambda_1))(1+o(1))`, (c) `lambda_1 * t0.toReal -> ∞` (product condition; follows from (b) and `log n -> ∞`), (d) `lambda_1 = o(log n) -> t0.toReal -> ∞`. Compared with manuscript line 349 (mixing times in W2, entropy, TV are `log d/(2 lambda_1)` under `liminf lambda_1 > 0` and `lambda_1 = o(log d)`): the W2 version needs no `o(log)` for (a)-(c) (Cor. 1.3 has none), which is correct, and (d) is correctly an implication.
  Hand check that (d) fails without the little-o: OU, `V_n = rho_n|x|^2/2 + c_n` with `rho_n = log n` (`liminf > 0`, rigid, `lambda_1 = rho_n`); `W2(Law X_t, mu)^2 = e^{-2 rho_n t}|x0|^2 + (n/rho_n)(1 - sqrt(1-e^{-2 rho_n t}))^2`; with `|x0| ~ c sqrt n`, threshold `W2 <= eta` is met at `t = (log n + O(1))/(2 rho_n) -> 1/2`. So `t0` stays bounded (and `t0 -> 1/2`), and the unconditional conjunct would be false. The implication form is right. Note (b) and (c) still hold there (`t0/t* -> 1`, `lambda_1 t0 ~ log n/2 -> ∞`).
- `mixing_time_kl_rigid`: hypotheses `IsRigidSequence`, `lambda_1 = o(log n)` (Cor. 1.4 hypotheses, as the manuscript), conclusions (a)-(d) unconditional, (d) legitimate since `hsmall` makes `t* -> ∞`. Any `eta > 0`: the cutoff profile goes `⊤ -> 0`, so any fixed `eta` works. No junk: `t0 < ⊤` eventually is asserted before `toReal` is used; `toReal ⊤ = 0` cannot make (b)-(d) vacuously true (they would fail at 0), so no exploitation.
- Not vacuous: `IsRigidSequence` satisfiable (OU with `rho` fixed, or `rho_n -> ∞` slower than... any rigid sequence), `meanBall` nonempty for `c > 0`.
