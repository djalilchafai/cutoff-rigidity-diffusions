## Definitions

- `mCurv X Y Z x = ∇_{X x}(∇_Y Z) - ∇_{Y x}(∇_X Z) - ∇_{[X,Y] x} Z`. In Mathlib `leviCivitaConnection I M Z y v` is ∇_v Z at y (section first, then point, direction), and the code uses it that way: `fun y => ∇ Z y (Y y)` is ∇_Y Z, differentiated in direction `X x`. `mlieBracket X Y = DY(X) - DX(Y)` is the standard bracket. So this is the standard R(X,Y)Z. Verdict: faithful.
- `mRic x v w = ∑ᵢ ⟨R(eᵢ,v)w, eᵢ⟩ = tr(X ↦ R(X,v)w)`, the standard Ricci. On the unit sphere R(X,Y)Z = ⟨Y,Z⟩X - ⟨X,Z⟩Y gives Ric = (n-1)g, positive. Sign confirmed. A flat test cannot detect the sign. The real sign test is that `bochner_identity` is kernel-proved with `+ mRic(∇f,∇f)`. At any x every tangent vector is ∇f(x) for some smooth f, so the identity determines the quadratic form `mRic(v,v)` given the other terms (mHessSq, mHess V, carre2 are defined independently). A wrong sign or a wrong convention would make the statement false on a sphere and unprovable. The proof (RicciBochner.lean) has the internal step `curv(∇f, Z_i, ∇f) = - mCurv(Z_i, ∇f, ∇f)`, consistent with Ric(∇f,∇f) = ∑⟨R(e_i,∇f)∇f, e_i⟩.
- `mExt x v`: constant coordinates in `trivializationAt x`. Smooth near x with `mExt x v x = v` (proved: `mExt_smooth`, `mExt_apply_self`). It is only defined/smooth on the trivialization domain; this is fine since mCurv is evaluated at x only, and `curv_tensor` (proved) shows the value at x depends only on the values of X,Y,Z at x for smooth fields. So `mRic` is the usual tensor, independent of the extension. Faithful. Note mCurv is not tensorial for non-smooth fields, but it is only used on smooth ones.
- `mHess f x v w = ⟨∇_v ∇f, w⟩`: standard (Hess f(v,w) = ⟨∇_v grad f, w⟩), symmetric for smooth f. `mHess V` is used in the bochner term as `⟨∇_∇f ∇V, ∇f⟩` = Hess V(∇f,∇f), matching manuscript ⟨Hess(V)∇f,∇f⟩. Faithful.
- `mHessSq f x = ∑ᵢ ‖∇_{eᵢ} ∇f‖²`: with orthonormal eᵢ this equals ∑ᵢⱼ Hess f(eᵢ,eⱼ)² = Hilbert-Schmidt norm squared. Faithful.
- Norms/inner products: I checked by elaboration with `pp.explicit` that `‖v‖` on `TangentSpace 𝓘(ℝ,F) x` uses `instNormedAddCommGroupOfRiemannianBundle…`, i.e. the Riemannian metric, not the model space norm. The inner product in `mgrad`/`carre`/`stdOrthonormalBasis` is the same instance, so the Riesz gradient and orthonormal basis are w.r.t. g. (Proof of CD_iff_ricci closes with `real_inner_self_eq_norm_sq`, confirming consistency.)
- `entropyOf` generalized: body unchanged (`∫ g log g - (∫ g) log(∫ g)`), only the type `Measure (Rd d)` replaced by `Measure α` with `[MeasurableSpace α]`. For α = `Rd d` the instance is the same, so all earlier uses (gibbs V, NoBm*, optimalLSI, talagrand-style statements, `optimal_constants_extremal`) keep their meaning (`NoBm*` files and `unfold entropyOf` proofs still refer to `CutCur.entropyOf`; the old `Statements.lean` copy is `d`-specific and equal on `Rd d`). Junk caveat (unchanged, shared with the earlier audited statements): non-integrable g gives integral 0, and `Real.log 0 = 0` gives the correct 0 log 0 = 0. Entropy of `g ≥ 0` is meaningful only for integrable g log g; the only use in this batch has g = f² bounded with compact support (see LSI below), where it is a genuine entropy. Also, for negative g the formula is not the entropy, but no statement here uses negative g (f² ≥ 0). Faithful.

## bochner_identity: faithful (remark only)
Manuscript lines 641-654: Γ₂(f) = Ric(∇f,∇f) + ‖Hess f‖²_HS + ⟨Hess(V)∇f,∇f⟩. Statement: pointwise, smooth V and f on any (not necessarily complete) manifold, with `carre2 = ½𝓛Γ(f,f) - Γ(f,𝓛f)` (matches Γ₂(f) = ½(𝓛Γ(f) - 2Γ(f,𝓛f))). No missing hypotheses (smoothness only), none superfluous. Smoothness degree `∞` for V, f; the metric is `∞`-smooth (instance `IsContMDiffRiemannianBundle … ∞`), which is enough for the Levi-Civita connection and gradient to be smooth. Remark: manuscript's "Bochner formula ∇𝓛 = 𝓛∇ - Hess(V)∇ - Ric(∇,∇)" is a vector-valued form; the statement is the scalar form, as flagged in the docstring ("scalar form only"). Not vacuous: Rd instances of the Riemannian bundle exist (`WitnessGeometry.lean`), and the identity is proved.

## CD_iff_ricci: faithful
`CD ρ V` (Γ₂(f) ≥ ρΓ(f) for all smooth f, no compact-support restriction) iff `∀ x v, ρ‖v‖² ≤ Ric(v,v) + Hess V(v,v)`. True for ρ of any sign and for smooth V with no completeness: (⇒) take a smooth g with ∇g(x)=v and Hess g(x)=0 (exists, local chart function times a bump; `exists_test_function`), where Bochner gives Γ₂(g)(x) = Ric+HessV(v,v); (⇐) Bochner plus `mHessSq ≥ 0`. The statement is the correct pointwise equivalent of manuscript (1.BErho) with g = metric. The CD class is all smooth f (not compactly supported), which is how the project's `CD` is defined, and equivalent as shown. Dimension-free CD(ρ,∞) only; the manuscript's CD(ρ,n) is not claimed.

## riemannian_k1_bounds: faithful with remarks
Manuscript line 154 (`k₁ ≤ d`, BaKl20 Lem. 14, Euclidean) and the Riemannian extension implicit in Theorem 1.9 (k₁ as the dimension of E₁); the manuscript does not state `1 ≤ k₁ ≤ dim M` for manifolds explicitly; this is a derived statement under Theorem 1.9's hypotheses (CD(ρ,∞), ρ > 0, λ₁ = ρ, complete connected, μ = e^{-V}vol probability). Flagged correctly: `hgap` is needed since on the round sphere S^d, ρ = d-1, λ₁ = d, k₁ = d+1 > dim.
- Non-vacuity: M = ℝ^d with V = ρ|x|²/2 + const: hμ holds, CD holds, λ₁ = ρ, k₁ = d, so 1 ≤ d ≤ d holds (d ≥ 1). `hgap` excludes the point manifold (F = 0): there the Rayleigh set is empty, `sInf ∅ = 0 ≠ ρ`. So no need for `0 < finrank F` here, and the conclusion `1 ≤ k₁` is not trivially false (the junk case is excluded). Consistent with `mSpectralGap_ge_of_CD` carrying `hF`.
- Junk in `mFirstEigenDim`: `finrank` of a span in L²(μ) of the smooth L² eigenfunctions for eigenvalue `mSpectralGap`. `finrank` is 0 if infinite dimensional, which would make `1 ≤ k₁` fail, not hold trivially; so there is no junk helping the conclusion. The span is over a.e.-classes of smooth L² eigenfunctions (manuscript: eigenspace of -𝓛 in L²(μ), eigenfunctions of the spectral gap are continuous/smooth, line 614-616 via GMS15). Equivalence of "smooth L² eigenfunction" with "L²-eigenvector of the Friedrichs/closure operator" relies on elliptic regularity and essential self-adjointness on complete manifolds; fine under the standing hypotheses (and proved in the project via `finiteDimensional_eigenClasses`, `mFirstEigenDim_eq_finrank`). Eigenvalue convention: `mgenerator f = -lam f`, i.e. 𝓛f = -λf. OK.
- Statement true: yes (proved, kernel-checked; injectivity of f ↦ ∇f(x₀) via parallel gradient on eigenfunctions with λ₁ = ρ gives k₁ ≤ dim).

## riemannian_poincare_lsi: faithful with remarks
Manuscript lines 618-632 mention λ₁ ≥ ρ and that Bakry-Emery gives "stronger functional inequalities such as a logarithmic Sobolev inequality" without stating constants. The statement: for smooth compactly supported f, ρ Var_μ f ≤ ∫‖∇f‖² and Ent_μ(f²) ≤ (2/ρ)∫‖∇f‖². These are the standard Bakry-Emery constants (Gaussian ρ = 1: Ent(f²) ≤ 2∫|∇f|²; consistent with the Euclidean LSI `H ≤ I/(2ρ)` in the project).
- Deviations: (a) the test class is smooth compactly supported rather than a "rich enough class"; the statement is weaker than the full H¹ inequality but equivalent by density on a complete manifold; harmless. (b) The constants are not printed in the manuscript for the Riemannian case (only the Euclidean `eq. LSI`), but are the standard ones; not a defect. (c) Hypotheses include `hμ`, completeness, connectedness, ρ > 0 (all needed; no `hgap`, none superfluous: Poincaré is just λ₁ ≥ ρ in Rayleigh form).
- Junk: f smooth with compact support implies f², f² log f² continuous and compactly supported, hence integrable for the finite measure μ; `variance f μ` is a genuine variance (f ∈ L²); `entropyOf` of f² ≥ 0 is the genuine entropy; log 0 = 0 consistent. `∫ ‖∇f‖²` is integrable (continuous, compact support). No `⊤`/`toReal` issues. `2/ρ` fine since ρ > 0.
- Not vacuous (Gaussian on ℝ^d; both inequalities then are the classical ones).
