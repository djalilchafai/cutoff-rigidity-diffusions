# Audit J: `exists_stdBrownian`, `exists_langevin` (Challenge.lean)

Verdict: faithful, no defect. Both are genuine non-vacuity statements for `IsStdBrownian` / `IsLangevin`.
Scratch tests (scratchpad `T.lean`, `A.lean`, compiled against `Challenge` and `CutoffRigidity.Paper.ExistsBrownian`) support the points below.

## (1) exists_stdBrownian
- `IsBrownianReal X P` = `IsPreBrownianReal` (for every finite `I : Finset ℝ≥0`, `HasLaw (fun ω => I.restrict (X · ω)) (projectiveFamily I) P`, i.e. AEMeasurable and the pushforward is the Brownian finite-dimensional law, a Gaussian with covariance min(s,t)) plus `∀ᵐ ω, Continuous (X · ω)`. Nothing is omitted: measurability is inside `HasLaw`, B 0 = 0 a.s. and covariance min follow (Mathlib lemmas `eval_zero_ae_eq_zero`, `covariance_eval`).
- Degenerate P: `HasLaw` forces P(univ) = pushforward mass = 1, so P is automatically a probability measure when d > 0. Checked in Lean: `probOf` (HasLaw to gaussianReal 0 1 implies IsProbabilityMeasure P) and `std_prob` (d > 0: IsStdBrownian B P implies IsProbabilityMeasure P). Hence the added `IsProbabilityMeasure P` in the statement is harmless/redundant for d > 0. For d = 0, `IsStdBrownian` reduces to `iIndepFun` over the empty family, which needs P(univ)=1 anyway (checked: example holds for any probability measure, and the unfolded goal is `P univ = 1`); so the extra clause matters only there and is needed.
- Teeth, proved in Lean (no sorry): `const_not_brownian`: for every measurable space, every P, every c, the constant process is not `IsBrownianReal` (B 1 would have law N(0,1), which has no atom, but a constant has an atom of mass 1). In particular the zero process, and any one-point Ω / Dirac P, fail. `std_const`: for d > 0, no constant `ℝ^d`-valued process is `IsStdBrownian`.
- Independence: `iIndepFun (fun i w (t : ℝ≥0) => B t w i) P` is the family of coordinates i : Fin d, each as a random element of path space ℝ≥0 → ℝ (whole paths, not single times). This is the right notion (independence of the coordinate processes). Its measurable space on path space is the product sigma-algebra, standard. Each coordinate is separately IsBrownianReal. Together these characterise standard BM on ℝ^d (Gaussian, independent coordinates, continuous). Orthogonal/rotation-invariance and independent increments follow.
- Universe: `Ω : Type` (universe 0) is harmless: all downstream statements are `Ω : Type*`, so `Type` is a legitimate instantiation (u = 0); non-vacuity at one universe is what is meant. The witness is Ω = Fin d → ℝ≥0 → ℝ with the product of the Degenne et al. Wiener measure `gaussianLimit`.
- d = 0: `Rd 0` is a singleton; statement true (trivially, witness exists); no issue.

## (2) exists_langevin
- `IsLangevin V B P X` = `ContDiff ℝ 2 V ∧ IsProbabilityMeasure (gibbs V) ∧ IsStdBrownian B P ∧ ∀ x₀, IsLangevinSolution V B P x₀ (X x₀)`. The existence statement does not assert `IsProbabilityMeasure P` separately only through IsStdBrownian; it adds it explicitly. Good.
- `IsLangevinSolution`: a.s. continuous paths and, for all t, X t = x₀ - ∫₀ᵗ ∇V(X_s) ds + √2 B t. The integral is an interval integral over s ∈ [0,t] ⊂ [0,∞), where `s.toNNReal = s`, so the index convention is exact. Because X is a.s. continuous and ∇V is continuous (V is C²), the integrand is continuous on [0,t], hence integrable: no junk value of the Bochner integral is possible a.s. Conversely the equation plus continuity pins the path: ∇V is locally Lipschitz, so by Gronwall the pathwise solution of the integral equation is unique, hence `X x₀` really is the (strong) solution of dX = -∇V(X)dt + √2 dB. So the predicate has real content and cannot be met by junk (e.g. a junk integral value would only matter for non-integrable integrands, which cannot occur here). Note the equation is required for all t simultaneously on one full-measure set, fine.
- Construction: X x₀ = `langevinProcess V B x₀` = `langevinSolution V (brownianDrivingPath B ω) x₀`, deterministic pathwise solution of the ODE for Y = X - √2 B (Y' = -∇V(Y + √2 B)); the proof uses `langevinProcess_continuous_paths_ae` and `langevinProcess_integral_equation_ae` with rate 0. Hypotheses of those lemmas: `IsEuclideanBrownian`, `ContDiff ℝ 2 V`, rate ≥ 0 and `rate‖z‖² ≤ Hess V z z`; nothing hidden beyond the statement's hypotheses. Global existence: convex C² V gives -∇V monotone (one-sided Lipschitz with constant 0) and locally Lipschitz, so no blow up; the translated drift y ↦ -∇V(y + √2 B_t) is monotone for each t, continuous in t. No extra hypothesis needed, and none present.
- Axioms (`#print axioms`): both `CutoffRigidity.Paper.exists_stdBrownian` and `exists_langevin` depend only on propext, Classical.choice, Quot.sound.
- Consistency of the hypotheses: V = ‖x‖²/2 + c (any c) is C², Hess = I ≥ 0, gibbs V = e^{-c} (2π)^{d/2} γ_d, a probability measure iff c = (d/2) log(2π); so the hypotheses are jointly satisfiable (for d = 0, gibbs V is the Dirac-mass-times-e^{-c}, probability for c = 0). The theorem hypotheses (hV, hHess, hgibbs) are all necessary only through IsLangevin's own clauses (hHess for the existence proof).
- Remark: hHess is `0 ≤ Hess V z z`, i.e. convexity of the C² function; the theorem is therefore proved for convex V, not for all C² V with probability gibbs (for non-convex V explosion can occur, e.g. V = -|x|^4-type potentials are excluded by gibbs integrability, but quartic-growth drift with a non-convex part could still be fine; not claimed). That is stated in the docstring and is enough for non-vacuity (the downstream theorems assume IsLangevin and RigidCurvature, which implies convexity anyway).

## (3) Link to downstream statements
`main_wasserstein_estimate`, `wasserstein_cutoff`, `langevin_entropy_decay` and others quantify over the very same `IsLangevin` (and `IsStdBrownian`) predicate defined once in Challenge.lean (see lines 158, 184, 245, 280, 317, 335, 429, 475, 507-509, 617, 630, 672-717). They use `{Ω : Type*}`, universe polymorphic; `exists_*` instantiate it at `Type`, which is a valid instance (u = 0); non-vacuity at one universe suffices, and `IsLangevin` for a larger universe can be had by transporting through ULift (measure-preserving), not claimed. Some downstream uses add `RigidCurvature` (implies Hess ≥ λ₁ > 0, so convex), within the scope of `exists_langevin` once gibbs is a probability, which is part of `IsLangevin`. For these, the family `V n` etc. are all satisfiable instances. One caveat: `exists_langevin` is an existence theorem for individual V; it does not by itself show that every combination of hypotheses of a given theorem (e.g. sequences with cutoff conditions) is satisfiable. That is outside the claim.
