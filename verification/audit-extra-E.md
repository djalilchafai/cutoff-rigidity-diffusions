# Audit E: `mSpectralGap_ge_of_CD` (Challenge.lean ~L812; manuscript lines ~619-663)

Verdict: FAITHFUL WITH REMARKS (no defect found). Statements/definitions read only; proofs not read. No Lean scratch files were needed.

## Statement
Connected, complete smooth Riemannian manifold M (model F, 0 < finrank F), V smooth, mu probability with mu = e^{-V} vol_g, rho > 0, CD(rho,infty)  ==>  rho <= mSpectralGap mu.
Manuscript: Ric + Hess V >= rho g implies lambda_1 >= rho (Bakry-Emery / Lichnerowicz), with CD(rho,infty) equivalent to (BErho) (stated in the manuscript).

## Definitions
- `mgrad`: Riesz representative of mvfderiv (differential): the Riemannian gradient. `carre f f = <grad f, grad f> = |grad f|^2`, matching Gamma(f) = |nabla f|^2 in the manuscript. `‖mgrad f‖^2` in the Rayleigh quotient is the Dirichlet energy density. OK.
- `mlaplacian` = trace (over an orthonormal basis of the tangent space) of the Mathlib Levi-Civita covariant derivative of grad f: the Laplace-Beltrami operator. `mgenerator = Delta f - <grad V, grad f>` = L of (eq:L:riem). `carre2 = L Gamma(f)/2 - Gamma(f, L f)` = Gamma_2(f) diagonal, matching the manuscript's Gamma_2 definition (diagonal, polarization identity). OK.
- `CD rho V`: for all f C^infty (ContMDiff top), all x, rho*Gamma(f)(x) <= Gamma_2(f)(x). This is exactly the manuscript's CD(rho,infty) ("for all f in a rich enough class": smooth is the standard rich class), and by the Bochner formula (Gamma_2 = Ric(grad f,grad f) + |Hess f|^2 + Hess V(grad f,grad f), pointwise, f smooth, V smooth) it is equivalent to Ric + Hess V >= rho g (take f with prescribed 2-jet at x). No junk: V is assumed smooth in the theorem (hV), so L Gamma etc. are genuine. Note: CD is stated for the Gamma_2 side, not Ric+Hess V; this is the manuscript's own abstract formulation, so fine. The docstring "equivalently Ric+Hess V >= rho g" is correct but that equivalence is not used by the statement.
- `IsWeightedVolume`: for every x0, the pushforward by chartAt x0 of mu restricted to the chart source equals Lebesgue on the chart target with density ofReal(e^{-V(chart^{-1} z)} * sqrt det g_ij(z)), g_ij = <d(chart^{-1}) e_i, d(chart^{-1}) e_j> in the Riemannian inner product on T_x M for e_i the orthonormal basis of F. Since every x lies in the source of chartAt x, these conditions determine mu uniquely on Borel sets, and it is e^{-V} vol_g with NO extra normalization constant (the constant is absorbed in V; probability then constrains V). The Lebesgue measure on F is the inner-product-space volume (orthonormal cube has volume 1), consistent with using an orthonormal basis in the Gram determinant. `ofReal` is harmless (argument is positive). The restricted map is only continuous-on the source, but source is open and mu.restrict is Borel, so Measure.map is not junk. OK. (Gram determinant is positive, so sqrt is the true volume density.)
- `mSpectralGap = sInf {Rayleigh quotients of smooth compactly supported f with 0 < Var f}`.
  * Set is nonempty and bounded below by 0 under the theorem's hypotheses (mu probability, hence M nonempty; positive dimension: M has >1 point, mu has full support since densities are positive, a smooth bump in a chart is non-constant, so has positive variance; the project even has `exists_pos_variance`). So sInf is the genuine infimum, no `sInf emptyset = 0` and no unbounded junk (nonnegative terms; compactly supported f: gradient bounded, integrals finite since mu finite; variance finite as f bounded).
  * Is the infimum over C_c^infty the true L^2(mu) gap of -L? On a complete Riemannian manifold with a locally finite weight e^{-V} (smooth), Lipschitz cutoffs by distance exist (proper metric thanks to completeness + Hopf-Rinow) and C_c^infty is dense in the Sobolev space W^{1,2}(mu) (Gaffney-type / Meyers-Serrin plus cutoff, finite mu so constants in the domain and Var is L^2-continuous). Hence inf over C_c^infty = inf over W^{1,2}(mu) = bottom of spectrum of -L on constants-perp (and -L is essentially self-adjoint on C_c^infty under CD + completeness, Bakry), i.e. the manuscript's lambda_1. For compact M, C_c^infty = all smooth, trivially right. Note that for a *noncomplete* M this would differ, which is why CompleteSpace is needed; it is included.
  * Direction relevant here: Lean claims rho <= inf over a subclass; since the true gap is a (larger-class) inf, the subclass infimum >= true gap >= rho would be the wrong implication direction in general, but density makes the two equal, so the statement is faithful. (If the density failed the Lean statement would be weaker than the manuscript, never stronger-by-accident.)
- Convention check: variance uses mu as a probability, equal to the usual Var; Rayleigh quotient int|grad f|^2 dmu / Var f is the standard Poincare constant. lambda_1 here = 1/C_P, so rho <= lambda_1 (Poincare with constant 1/rho), consistent with Bakry-Emery.

## Hypotheses
- `0 < finrank F` (amendment): F trivial forces M a discrete space; with ConnectedSpace M and nonempty (probability measure), M is a point, every smooth f is constant, Var = 0, Rayleigh set empty, mSpectralGap = sInf empty = 0, CD holds trivially (all Gamma = 0, Gamma_2 = 0 >= 0... both sides 0), weighted-volume holds (chart target is the single point of F={0}, Lebesgue = Dirac, density e^{-V}*1 = 1 for probability), so rho <= 0 fails: the amendment is NECESSARY. It is sufficient: for finrank F > 0 and M connected with mu a probability (nonempty M), the Rayleigh set is nonempty (argument above), so no hidden degenerate case. The "F nontrivial but M a point" case is impossible (M would be locally homeomorphic to an open subset of F, which has no isolated points; a chart onto an open set with a single point is impossible in positive dimension). ConnectedSpace M is not even needed for non-emptiness of the Rayleigh set when finrank>0; it is part of the manuscript's standing hypotheses (and gap is 0 on a disconnected M, so it IS needed for truth: disconnected M with mu probability has functions locally constant, Var>0, grad = 0, Rayleigh quotient 0 < rho). Present, correct.
- `CompleteSpace M` + `IsRiemannianManifold`: ties the emetric to the Riemannian distance; completeness as in the manuscript.
- `[IsProbabilityMeasure μ]`: manuscript's mu = e^{-V}vol is a probability (normalization implicit); needed for Var / L^2 meaning. Note that it, together with IsWeightedVolume, makes e^{-V} integrable (so V -> infinity in an integrated sense); not a deviation.
- `hV` smooth, `hρ : 0 < ρ`: as in the standing hypotheses. rho > 0 is not strictly needed for rho <= lambda_1 (for rho <= 0 it is trivial since gap >= 0), harmless.
- Mathlib Levi-Civita connection presupposes the smooth Riemannian bundle (instance `IsContMDiffRiemannianBundle`), included.

## Non-vacuity (WitnessMain.lean `exists_riemannian_instance`)
For k > 0, rho > 0: M = F = R^k (Euclidean, standard metric), V = rho|x|^2/2 + (k/2) log(2 pi/rho), mu = gibbs V = N(0, rho^{-1} I). The witness provides ContMDiff V, IsProbabilityMeasure, IsWeightedVolume (Rd k) mu V, CD (Rd k) rho V, mSpectralGap = rho, and k = finrank >0 (hk); instances ConnectedSpace, CompleteSpace, IsRiemannianManifold on Rd k are used by the sibling `splitting_applies`, which type-checks them. So all hypotheses hold with rho>0 and the conclusion reads rho <= rho: consistent (the Gaussian is the equality case, as in Lichnerowicz). The witness is flat only, so non-vacuity in curved cases is not tested but the hypotheses are not contradictory; the Rayleigh definition was matched to the audited Euclidean `spectralGap` via `mSpectralGap_rd`.

## Deviations
1. (informational) amendment `0 < finrank F`: necessary and sufficient (see above). Harmless.
2. (informational) the L^2 gap is defined via C_c^infty Rayleigh quotients rather than the self-adjoint operator spectrum; equal on complete M by density. Non-trivial analytic fact but correct.
3. (informational) CD is formulated through Gamma_2 >= rho Gamma on smooth f, not Ric + Hess V >= rho g; equivalent by Bochner, and matches the manuscript's own abstract formulation.
